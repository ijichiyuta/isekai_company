# アートバイブル：異世界カンパニー

**版数**: v1.0（M1確定）
**目的**: 全アセットの視覚的統一を担保する唯一の基準。AI生成・自作を問わず、すべてのビジュアルアセットは本書の規定に従い、`tool/asset_pipeline` の量子化・監査を通過しなければならない（要件 §21.2 / AC-17）。

> 統一感の欠如が同人ゲーム臭さの最大要因である（要件§7 アセット要件）。ここは妥協しない。

---

## 1. 基本方針

- **外注ゼロ・フルAI内製**（要件§0.3）。統一感はアートバイブル固定＋量子化パイプライン＋量産テストゲートで担保する
- 温かみのある「羊皮紙とインク」の異世界商人世界観。カイロ系の親しみやすさ ＋ なろう系ファンタジーの彩度

## 2. 解像度・グリッド（固定）

| アセット種別 | ドット解像度 | 表示スケール |
|---|---|---|
| 商品アイコン | 32×32 | 整数倍（×2/×3）のみ |
| 素材アイコン | 32×32 | 整数倍のみ |
| 従業員パーツ（顔・表情） | 48×48（顔）/ 64×96（全身） | 整数倍のみ |
| 施設 | 64×64 | 整数倍のみ |
| UIアイコン | 24×24 | 整数倍のみ |

- **アンチエイリアス禁止**（ドットのエッジは硬く保つ）。拡大は最近傍補間（nearest neighbor）のみ
- 非整数スケール表示禁止（ドットの潰れを防ぐ）

## 3. パレット（固定・32色）

- **使用色は `assets/palette.json` の32色に限定**。中間色・グラデーションの新規色を勝手に足さない
- パレットは5つのランプ（明→暗の階調）＋アクセントで構成:
  - **羊皮紙/生成り**（背景・UI地）4色
  - **茶/革**（枠・木材・革製品）5色
  - **金/黄**（資金・光沢・ハイライト）4色
  - **緑**（植物・薬草・自然）5色
  - **青/水**（水・空・冷却・魔法）5色
  - **赤/橙**（火・警告・食品）5色
  - **紫**（名声・魔族・高級）2色
  - **無彩色**（黒インク・白・灰）2色
- 影は「同ランプの1〜2段暗い色」を使う。黒ベタの影は禁止（羊皮紙世界の柔らかさを保つ）

## 4. 光源・陰影（固定）

- **光源は常に左上（10時方向）**。ハイライトは左上、影は右下
- 陰影は2段まで（ベース色＋影1段、強調時のみ影2段）。過度なグラデ禁止
- 商品アイコンは「1pxの暗色アウトライン（茶ランプ最暗色 `#2A1E14`）」で囲む。純黒アウトライン禁止

## 5. アウトライン規則

- 全アイコンは1pxの選択的アウトライン（外周のみ、内部の細部はアウトラインなしで色差で表現）
- アウトライン色はオブジェクトの主色ランプの最暗色（真っ黒は使わない＝「セレクティブアウトライン」）

## 6. 従業員グラフィック（パーツ合成・必須）

- 1体ずつ描く方式は**禁止**（個人開発では破綻、要件§21.2）
- 種族（4→8）× 表情（3）× 職能装備（4→6）のパーツを合成して生成
- パーツは共通の骨格グリッド（48×48顔基準）に整列。差分は顔・髪・肌・装備レイヤー

## 7. 制作パイプライン（AC-17）

すべてのアセットは以下を通過すること:

```
AI生成 or 自作
  → tool/asset_pipeline quantize   （固定パレットへ減色＋サイズ正規化＋近傍補間）
  → tool/asset_pipeline audit      （パレット逸脱ゼロ・サイズ・透過を検査）
  → assets/generated/ に格納
  → アセットCI（.github/workflows/ci.yml の asset-audit ジョブ）が全点を再監査
```

- **AI生成は「スタイル参照固定＋同一プロンプトテンプレート」で行う**。テンプレートは `assets/prompts/` にリポジトリ管理
- 量子化は機械的にAI出力を固定パレットへ収束させる（AIのパレット揺れを吸収する安全網）

## 8. M1 量産テストゲート（要件§24 / §25）

**顔グラ1種族＋アイコン20点を量産し、統一感を自己審査（/game-visual-qa）で合格させるまで本量産に入らない。**
不合格ならスタイル参照を再固定してからやり直す。この環境では実AI画像生成が行えないため、実アセットの量産テストは画像生成が可能なセッションで実施する（パイプライン・監査・パレット・アートバイブルの基盤はM1で確定済み＝本書 ＋ `assets/palette.json` ＋ `tool/asset_pipeline`）。

## 9. プロンプトテンプレート（AI生成の統一化・雛形）

`assets/prompts/` に種別ごとのテンプレートを置く。共通接頭辞:

```
32x32 pixel art icon, {subject}, warm fantasy merchant style,
selective dark-brown outline (no pure black), light source top-left,
limited palette (parchment/leather/gold/green/blue/red),
no anti-aliasing, no gradient banding, flat 2-tone shading, centered, transparent background
```

`{subject}` 例: "a cup of pudding / プリン", "a bar of soap / 石鹸", "an iron gear / 歯車"。
生成後は必ず量子化パイプラインを通し、パレットへ収束させる。
